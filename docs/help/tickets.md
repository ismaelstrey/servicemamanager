# Tickets

Guia de funcionalidades de tickets: criação, filtros, visualizações e comentários.

## Backend
- Rotas: `/api/tickets` (lista, criação, detalhes, atualização).
- Validações e serviços com Prisma.

## Frontend
- Página de lista com filtros avançados (status, data, tags).
- Visualizações: lista, grid, kanban.
- Form com validação e anexos.
- Hooks de API conforme padrão do projeto.
