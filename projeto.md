 Prompt para Trae: Sistema de Gerenciamento de Provedores
Título do Projeto: Sistema de Gerenciamento de Provedores com Workspace Inteligente
Descrição: Desenvolver um sistema web moderno para empresas que prestam serviços a provedores de internet. O sistema deve centralizar todas as operações relacionadas a cada provedor atendido, oferecendo uma experiência fluida e organizada por meio de workspaces dedicados.
Funcionalidades:
- Gerenciamento de tickets com vinculação automática ao provedor
- Cadastro e inventário de equipamentos: Switches, OLTs, roteadores, servidores, virtualizadores
- Cofre de senhas seguro com controle de acesso
- Workspace por provedor com dashboard contendo:
- Quantidade de equipamentos
- Links ativos
- Cofre de senhas
- Tickets abertos e resolvidos
- Dados cadastrais da empresa
- Visualizações de ordens de serviço em:
- Lista
- Grade
- Kanban
Tecnologias:
- Framework React com TypeScript
- Estilização: styled-components com suporte a templates de temas
- Banco de Dados: PostgreSQL com ORM Prisma JS
- Arquitetura: componentes com responsabilidade única, código limpo e organizado, seguindo boas práticas de Clean Code e SOLID
Extras com IA (opcional):
- Sugestão de prioridade de tickets com base em histórico
- Previsão de falhas em equipamentos
- Chat inteligente para suporte interno
